## Certified Red Team Analyst (CRTA)
A practical certification covering Active Directory enumeration, privilege escalation, lateral movement, credential attacks, and post-exploitation techniques used during internal network assessments.

![CRTA](https://raw.githubusercontent.com/JustFernandezz/cyb3lnkuei-site/refs/heads/main/static/images/CRTA.jfif)

Issued by Altered Security.

## Certified AppSec Practitioner
An application security certification focused on identifying, validating, and mitigating common vulnerabilities in web applications and APIs. It covers secure development principles, vulnerability assessment, and hands-on testing aligned with modern application security practices.
![CAP](https://raw.githubusercontent.com/JustFernandezz/cyb3lnkuei-site/refs/heads/main/static/images/Certified%20Appsec%20Practitioner.jfif)

Issued by Secop Group

## Certified Network Security Professional
A certification focused on network security fundamentals, including network architecture, secure protocols, threat detection, firewall technologies, intrusion prevention, and defending enterprise networks against common attacks.
![CNSP](https://raw.githubusercontent.com/JustFernandezz/cyb3lnkuei-site/refs/heads/main/static/images/Screenshot%20(555).png)

Issued by Secops Group
